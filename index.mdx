Flame is static typed, multiparadigmal, memory-safe(indev) language that transpiles into C\+\+. Current docs are targeting Flame 0.10.0. Its inspired by zig, c\+\+ and rust.

<Warning>
  Language is still in development, some features may change in the future!
</Warning>

<Accordion title="Why Flame over C++?">
  Flame is more secure for coding, it will warn you about something that C++ would ignore, and it will patch generated C++ code to prevent UB.
</Accordion>

<Accordion title="Why Flame over Rust?">
  Flame have easier syntax and have nearly same performance as Rust. And Flame offers faster compilation speed. 
</Accordion>

<Accordion title="Why Flame over C?">
  Flame is modern language that aims to remove C/C++ UB and  add modern features into C-like syntax. 
</Accordion>
